# Submission screenshots

Capture these views while the app is running at `http://localhost:5173`:

1. `01-admin-today.png` - Admin Today view.
2. `02-workboard.png` - an assigned task on the Workboard.
3. `03-library.png` - a PDF or TXT document in the Library.

5. `05-pulse.png` - Admin Pulse with task and search analytics.

Keep the browser window wide enough to show the navigation and the main content.
